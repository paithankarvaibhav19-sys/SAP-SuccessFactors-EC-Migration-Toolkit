## 1. Architectural Overview & Scope

This specification details the middleware integration pattern using SAP Cloud Integration (CPI) on SAP Business Technology Platform (BTP). It defines the pipeline architecture for migrating delta worker transactions from legacy staging repositories into SAP SuccessFactors Employee Central using atomic OData v2 `$batch` operations.

```text
┌─────────────────────────┐
│  Legacy Staging / SFTP  │
└────────────┬────────────┘
             │ (HTTPS / SFTP Poller)
             ▼
┌─────────────────────────────────────────────────────────────────┐
│                    SAP Cloud Integration (CPI)                  │
│                                                                 │
│  [ XML/JSON Converter ] ──> [ Content Modifier ]                │
│                                      │                          │
│                                      ▼                          │

### 2. CPI iFlow Pipeline Components

| Pipeline Stage | CPI Palette Element | Technical Function |
| :--- | :--- | :--- |
| **Ingestion** | HTTPS / SFTP Adapter | Ingests formatted worker transaction files from migration staging. |
| **Authentication** | Security Material / OAuth2 | Generates SAML Bearer assertion tokens for SuccessFactors API access. |
| **Transformation** | Groovy Script / Mapping | Formats UTC timestamps, maps picklist codes, and builds multipart payloads. |
| **Batching** | Content Modifier | Wraps multiple entity upserts into a single atomic MIME multipart changeset. |
| **Dispatch** | HTTP / OData v2 Receiver | Issues `POST` request to `/odata/v2/$batch` endpoint. |
| **Error Handling** | Exception Subprocess | Captures 4xx/5xx HTTP responses and routes errors to an administrative DL. |



### 3. OData v2 Multipart $batch ChangeSet Architecture
Using $batch ensures transactional atomicity: if an employee's EmpJob record fails validation, the associated PerNationalId record within the same changeset is rolled back automatically.

### 4. Groovy Script Transformation Example: Timestamp & Code Standardization


This script runs inside the CPI pipeline to clean incoming timestamps and format them for SuccessFactors OData JSON requirements:


import com.sap.gateway.ip.core.customdev.util.Message
import groovy.json.JsonSlurper
import groovy.json.JsonOutput
import java.text.SimpleDateFormat

def Message processData(Message message) {
    def body = message.getBody(String)
    def jsonSlurper = new JsonSlurper()
    def payload = jsonSlurper.parseText(body)

    // Standardize legacy date string (YYYY-MM-DD) to epoch milliseconds
    if (payload.EFFDT) {
        def sdf = new SimpleDateFormat("yyyy-MM-dd")
        def date = sdf.parse(payload.EFFDT)
        payload.startDate = "/Date(" + date.getTime() + ")/"
    }

    message.setBody(JsonOutput.toJson(payload))
    return message
}


### 5. Error Classification & Operational Troubleshooting

| HTTP Status | Error Scenario | Resolution Procedure |
| :--- | :--- | :--- |
| **401 Unauthorized** | Expired SAML/OAuth token or misconfigured API key. | Regenerate OAuth client assertion in Security Material. |
| **400 Bad Request** | Invalid Picklist option ID or broken MDF Association. | Validate parent-child relationship (e.g., BU to Division link). |
| **500 Internal Error** | Lock contention on employee historical timeline. | Enable sequential processing in CPI Splitter to avoid parallel writes on the same `userId`. |
