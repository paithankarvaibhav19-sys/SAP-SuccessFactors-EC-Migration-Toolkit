## 1. Architectural Overview & Scope

This technical design document outlines the configuration blueprint for automating business logic in SAP SuccessFactors Employee Central. It details the transition from legacy manual HR approvals and XML event-reason derivation to the Metadata Framework (MDF) Business Rules Engine, defining automated validation rules, dynamic workflow approval routing, and Event-Reason Derivation (ERD).

---

## 2. Rule Execution Architecture & Trigger Hooks

Business rules in Employee Central execute across specific UI life-cycle events attached via Business Configuration UI (BCUI) or Configure Object Definitions:

```text
User Actions in UI (Hire / Transfer / Promotion / Job Change)
                           │
                           ▼
┌─────────────────────────────────────────────────────────┐
│                    Trigger Hooks                        │
│                                                         │
│  [ onInit ]        ── Executes when opening the UI / form│
│  [ onView ]        ── Executes when viewing record data  │
│  [ onChange ]      ── Executes when a field value changes│
│  [ onSave ]        ── Executes when submitting changes   │
│  [ saveAlert ]     ── Generates alerts after save        │
└────────────────────────────┬────────────────────────────┘
                             │
                             ▼
┌─────────────────────────────────────────────────────────┐
│                Evaluated Target Engines                 │
│   • Field Auto-Population & Set Visibility / Required   │
│   • Event-Reason Derivation (ERD Rule)                  │
│   • Workflow Routing Definition (Approver Hierarchy)    │
└─────────────────────────────────────────────────────────┘
