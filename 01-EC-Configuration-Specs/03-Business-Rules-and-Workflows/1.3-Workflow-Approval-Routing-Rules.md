## 1. Architectural Overview & Scope

This technical design document outlines the configuration blueprint for automating business logic in SAP SuccessFactors Employee Central. It details the transition from legacy manual HR approvals and XML event-reason derivation to the Metadata Framework (MDF) Business Rules Engine, defining automated validation rules, dynamic workflow approval routing, and Event-Reason Derivation (ERD).

## 3. Rule Trigger Hook Classification

| Trigger Hook | Execution Point | Primary Use Case in EC |
| :--- | :--- | :--- |
| **`onInit`** | When loading a new employee creation or edit screen. | Setting default initial values (e.g., Default Currency, Standard Country). |
| **`onChange`** | When a specific field value is modified by a user. | Cascading updates (e.g., Department change auto-sets Cost Center, calculating FTE). |
| **`onSave`** | When user clicks Save/Submit, prior to database commit. | Cross-field validations, Event-Reason Derivation, Workflow determination. |
| **`saveAlert`** | Evaluated post-save on scheduled batch jobs or save events. | Expiration tracking (e.g., Visa expiry, Probation completion reminders). |


4. Business Rule: Event-Reason Derivation (ERD)
The Event-Reason Derivation rule automatically derives the technical event (e.g., DATA_CHANGE, PROMOTION, TRANSFER) and the specific event reason without requiring manual recruiter/HR selection.

4.1 Rule Specification: Job Promotion with Pay Adjustment
Base Object: Job Information Model

Trigger Event: onSave

Rule Logic (Pseudocode):
IF 
   Job Information Model.Job Code != Job Information Model.Previous.Job Code 
   AND Job Information Model.Pay Grade > Job Information Model.Previous.Pay Grade
THEN
   SET Job Information Model.Event = "Promotion" (PROM)
   SET Job Information Model.Event Reason = "Promotion with Salary Revision" (PROM_SAL)
ELSE IF 
   Job Information Model.Location != Job Information Model.Previous.Location
THEN
   SET Job Information Model.Event = "Transfer" (XFER)
   SET Job Information Model.Event Reason = "Location Transfer" (XFER_LOC)

6. Business Validation Rule: Prevent Invalid FTE and Pay Allocations
Base Object: Job Information Model

Trigger Hook: onSave

Rule Definition:
IF 
   Job Information Model.Standard Weekly Hours > 48 
   AND Job Information Model.Country == "IND"
THEN
   RAISE ERROR MESSAGE "ERR_EXCEEDS_MAX_LEGAL_HOURS": "Standard weekly working hours cannot exceed 48 hours under statutory labor regulations."
